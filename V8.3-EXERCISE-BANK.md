# MathKid 4 Pro V8.3 Preview – Kho 1.000 bài tập offline

## Status
Implemented on `feature/v8.3-exercise-bank` from the V8.2 Windows development branch. The V8.1 Android and V8.2 Windows sources remain unchanged. **Build/test success on GitHub Actions and device testing are not yet confirmed.** This is a preview, not an official SGK question bank.

## Actual scope
- `ExerciseBank.js` generates exactly **1,000 unique exercise prompts** (and 1,000 unique IDs) deterministically on the device from topic-specific templates, each with integer answer, short worked explanation and skill tag.
- Allocations: Số tự nhiên 120; Cộng/trừ 120; Nhân/chia 160; Tính nhanh/biểu thức 120; Phân số 120; Hình học 100; Đại lượng 80; Toán lời văn 100; Tư duy 80.
- These are **1,000 distinct numerical instances generated from reusable patterns**, **not** 1,000 independently written or curriculum-reviewed questions. They complement, rather than replace, the original 120 lesson cards, 120 per-card checks, synthetic topic generator and four fixed matching game designs.
- Select a group or all nine mixed groups, level tag, and 10 or 20 questions. Previously correct IDs are deprioritized; unfinished/incorrect ones appear first. After most of a group is mastered, solved items top up the session.
- Each completed bank session records full answer history using the existing `history` schema (mode `bank`). A session may earn 0–3 stars under the existing completion threshold, usable in the V8.1 shop. Shop wallet fields and historic stars are preserved.
- Bank progress is derived from unique correctly completed exercise IDs; no new storage key or destructive data migration.
- Windows uses the same source, offline bundle and desktop JSON save/open; Android has same bank functionality and JSON transfer.

## Compatibility and validation
- Keep `mathkid4_v1_progress`; normalizeProgress retains history, seen, lessonChecks, stars, starSpent, ownedRewards and equippedReward.
- The user should export backup JSON from the actual device before trying new build. Android and Windows local data do not automatically synchronize.
- `tests/exercise-bank.test.mjs`: allocation, 1,000 unique prompts, numeric answers, solutions, group mixing, mastery and repeat selection.
- `tests/navigation-shop.test.mjs`: Android Back from bank and bank quiz.
- Run all existing regressions via `npm test` in GitHub Actions.

## Build and acceptance
- Android APK workflow: `.github/workflows/android-apk.yml`, artifact `MathKid4-V8.3-android-apk`.
- Windows portable EXE workflow: `.github/workflows/windows-exe.yml`, artifact `MathKid4-V8.3-Windows-EXE`.
- These are CI artifact names **only if** workflows complete successfully. They are not confirmed downloads or signed public releases.
- Test on Android and Windows: catalog shows 9 groups / 1,000 questions, 10/20-question sessions, wrong answer explanation, progress count, saved history, earned stars, shop balance, repeat/open app, JSON backup and restore.
- Regression: 120 cards, shark (correct/incorrect/timeout/splash), five lands, 4 matching games, offline tutor, Android Back and Windows JSON dialogs.
- Replacing an internal APK could require uninstall if GitHub runner signing differs. Export JSON from the installed APK first. Portable EXE is unsigned, so company policies may block execution.

## Follow-up content review
Difficulty tags currently rotate across question instances, **not a validated pedagogical level system**. Editorial review, better difficulty grading, curricular alignment by textbook and richer illustrations are planned for the next content revision.
