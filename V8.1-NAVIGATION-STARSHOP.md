# MathKid 4 V8.1 Preview – Android navigation and Star Shop

## Two issues addressed

1. **Android swipe/back:** register BackHandler for Android system Back/edge-swipe, returning to a parent screen instead of exiting. On the app's Menu screen, Back asks for confirmation before exiting. Visible Home/Menu buttons are added to standard headers and compact game/quiz screens.
2. **Virtual rewards:** six fixed-price, non-random companion badges (🧭 🚀 🦕 🧙 🐉 🏰). Earned stars remain a lifetime record; remaining spendable balance is `stars - starSpent`. A purchased companion can be equipped and is shown on Home. No money, advertising, or purchases.

## Save compatibility

- The key remains `mathkid4_v1_progress`.
- New fields: `starSpent`, `ownedRewards`, `equippedReward`.
- V5–V8 progress migrates with empty shop inventory and 0 spent, preserving history, badges, lesson checks and maps.
- Existing JSON backup format V2 automatically includes the new fields. Purchases are stored before the UI displays success; duplicate and insufficient-funds purchases are rejected.
- Historic total stars and stage records are never reduced by spending.

## Install test / signing warning

**Before replacing the existing V8 APK, export the JSON backup FROM THE APK currently installed on the phone**, not just from Expo Snack. Save it outside the application and verify the file opens and includes `history`. Also keep the older APK until V8.1 works.

GitHub Actions currently compiles a release artifact with the project's temporary build signing configuration. Different GitHub runners may use different signing keys. Consequently Android may say the new APK cannot update an installed app with the same package name. If this happens:
1. Confirm a usable JSON backup was saved outside the old app.
2. Uninstall the old APK (this removes app-private progress), install the new APK.
3. In MathKid → Góc bố mẹ → Sao lưu dữ liệu, paste and validate the JSON before restoring.
4. Verify history, stars, completion and shop balance after restore.

For seamless in-place updates in a future production release, configure persistent Android signing credentials (e.g. EAS signing) rather than temporary runner keys. Never put signing keys in this public repository.

## Acceptance checks

- Open 120 cards, quiz, shark, drag and parent screens. Android swipe inward from either system back edge; it returns to a parent screen and keeps MathKid open. At Menu, swipe shows the exit confirmation.
- A visible Home/Menu button works on compact quiz/shark and standard screens.
- A legacy 9-star record begins with 9 usable stars, unchanged history and stage badges.
- Buy 3-star companion: spendable balance becomes 6 and lifetime earned remains 9; buying same companion again is not possible.
- Buy an 8-star companion when balance is 6: disabled, no negative balance.
- Equip a purchased companion and check the icon on the home hero.
- Close/reopen app and verify inventory, equipped companion and balance remain.
- Export/restore JSON and confirm wallet/inventory are retained.
- Check all V8 game and offline flows again.

The V8.1 code and APK produced by this workflow are **internal-test candidates** until device confirmation.
