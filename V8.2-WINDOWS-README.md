# MathKid 4 Pro V8.2 – Windows EXE (Release Candidate)

## Status
Source code and GitHub Windows build workflow are committed on `feature/v8.2-windows-exe`. **A successful EXE build and a real Windows run have not yet been verified.** The V8.1 Android branch is unchanged.

## What is included
- Windows Electron wrapper around the **same Expo Web bundle** as the V8.1 MathKid app; retains 120 learning cards, Gia sư, 5-land Adventure, shark animation, fraction coloring, 4 matching games, offline practice, Star Shop and parent dashboard.
- Windows offline bundle is shipped inside the EXE. The desktop app does not need Expo Snack or a web server after installation.
- A stable private `mathkid://app` origin enables browser-local AsyncStorage persistence in the desktop app. No new learning-profile key; existing schema `mathkid4_v1_progress` stays unchanged.
- Native desktop file dialogs in Góc bố mẹ → Sao lưu dữ liệu: **save JSON file** and **open JSON file**. Existing V1/V2 backup format, preview/confirmation and pre-restore backup remain in place.
- Shared source code with Android. New Electron code uses sandbox, context isolation, no Node integration or arbitrary website navigation.
- Desktop home page uses a wider layout; quiz and game views retain their safe fixed-footer layout.

## Downloading the EXE
Open [GitHub Actions – Windows EXE](https://github.com/dangduythu/thu.dang/actions/workflows/windows-exe.yml) and select a **successful** workflow run on this branch. In Summary → Artifacts, download `MathKid4-V8.2-Windows-EXE`, unzip, and run `MathKid4-V8.2-Windows-8.2.0-rc.1-x64.exe` (the exact artifact file name may vary with build metadata).

The target is a **portable 64-bit Windows EXE**. It is unsigned test software, so Windows SmartScreen or company IT rules may warn or block it. Do not bypass organization policy; a production rollout should use persistent code signing.

## Moving existing Android history and rewards to Windows
1. In **the Android app currently holding your latest progress** go to Góc bố mẹ → Sao lưu dữ liệu.
2. Save the complete `mathkid4-backup` JSON externally. This includes total stars, spent stars, owned companions, history, lesson checks and stage records.
3. On Windows open MathKid → Góc bố mẹ → Sao lưu dữ liệu → **Mở tệp JSON từ máy tính**.
4. Review sessions/questions/stars/lessons and explicitly confirm restore.
5. Verify the Star Shop balance and owned companions, learning history and badges.
6. For future transfer in the other direction, choose **Lưu JSON thành tệp trên máy tính** and import that JSON on Android.

**There is no automatic sync between Android, Snack and Windows.** Local progress on each platform remains separate unless you intentionally transfer JSON. A stale backup can overwrite newer progress; compare summaries first.

## Building on GitHub
`.github/workflows/windows-exe.yml` builds with `windows-latest`: install dependencies, align Expo packages, execute regression tests, export web to `dist/`, package via Electron Builder portable x64, and upload a downloadable EXE ZIP artifact. Neither Android Studio nor a local Node install is needed for the user to download the resulting build.

## Verification checklist
- Start EXE offline, close and relaunch; ensure earned stars/owned rewards and learning history remain.
- Windows controls: mouse, keyboard, Enter on answers, and Menu buttons.
- Start and complete every original V8.1 mode (including shark timeout/splash, 4 matching games, five regions).
- Test save JSON, import JSON preview/confirm, and legacy V1/V2 restore without losing progress.
- Compare latest Android totals with the Windows imported profile.
- Run on Windows 10/11 x64. No ARM/32-bit build configured.

**Do not merge this preview to main until CI and real-device testing succeed.**
